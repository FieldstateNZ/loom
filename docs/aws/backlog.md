Memory writes, scheduling/delegation, external messages, remote character downloads and simulation integration require their own bounded permission/provenance/recovery designs. They are not enabled by approving task inbox capture. Blender generation and body/speech research do not block A0–A5.

Implementation order for the first cloud pilot: **A0 + A1 → A2/A3/A4 → A5**, with **A6/A7/A8** progressing locally as contracts permit. **A9** verifies the full experience. The live portion waits for the user's explicit deferred-test decision; the independent work does not wait. **A10/A11** retain the route to production/OASP rather than shrinking the goal to the development tier.
