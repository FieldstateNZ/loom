# Compatibility and evidence matrix

Part of the [AWS decision](README.md), 27 October 2026. **Local verified** means the specified scope, not live AWS operation or a production-quality assistant. Source references below are immutable; draft branches must land or be explicitly selected before release.

| OpenAI conversation path | Loom #48/#50 direct Responses, owned history, function calls, SSE parsing; actual HTTP gateway tests use simulated Responses | Real model availability, response quality, actual usage and latency; no live key used | Loom + Tandem; live test remains deferred |

| Confirmed task capture | #50 proposal/decision/dispatch ledger + #131 atomic operation receipts; Tandem API passes 19 real-service checks | Native exact-detail confirmation, live streamed result and AWS endpoint execution pending | Tandem + Loom + LucidBrain |
| Cancellation/retry | Before-dispatch cancellation prevents write; lost committed replies recover original UUID; duplicate confirmation does not write again | A canceled unknown dispatch with no visible receipt has no authoritative no-effect/cancel tombstone | LucidBrain operation fencing first, then Loom/application recovery; do not erase the unknown |

| OASP events/replay/tool-result lifecycle | Types/store work exists for session events/pending calls | No complete real OpenAI `AgentProvider` adapter, resource/vault mounts, `migrate` or replayable native event path is proven | Loom/OASP; preserve existing HTTP path while adding bounded conformance work |

| PostgreSQL | Loom tests PG16 and recorded PG18 CI profiles; LucidBrain service tests use PostgreSQL16/test schema | Full LucidBrain migration chain with pgvector, restricted roles, TLS verification and restore are **not** qualified by fixture tests | Loom/LucidBrain DB owners; PostgreSQL16 + pgvector proposed initially |
| Migration lifecycle | SQLx embedded migrations; LucidBrain filename-tracked SQL runner with per-file transactions | Loom migration-only command; LucidBrain single migration lock/runtime entrypoint split; no DDL runtime credential | Owning repos; one controlled migrator per release |
| Object/file storage | Text memories/tasks live in LucidBrain database; Riley is bundled in iOS | LucidBrain Spaces integration currently requires explicit key/secret; AWS workload-role S3 adaptation and file permissions are not automatic | LucidBrain/character pipeline; file uploads/downloads outside first pilot |
| Streaming on phone | Loom upstream safe activity/keepalives and completed answer parts | Tandem currently returns final JSON; proxy tuning does not create client streaming, event replay or Realtime voice | Tandem + Loom; authenticated reconnect/interrupt contract first |
| Multi-replica operation | Conversation/action guards and keyed receipts serialize actual writes across replicas; batch submission has an atomic claim | Process-local rate/budget cache, batch crash reconciliation, unused LucidBrain startup worker and migration/shutdown coordination | One replica, no overlapping rollout; shared controls gate scale |
| AWS infrastructure | Seven scoped task routes synthesize into existing control Lambda; 48 backend/infrastructure tests pass | Full runtime/DB/proxy/IAM/backup/schedule IaC and real AWS smoke missing | AWS hosting owner + Tandem; no new resources in this design PR |
| Shared platform | Reviewed k3s/AKS ownership, Helm patterns and desired-state repos | No verified AWS Fabric hosting source; ECS registration/reconciliation is not implemented by Kubernetes code | Resolve hosting ownership before new foundation; no client/platform mutation here |
| Simulation provenance | Task policy requires real-world provenance at app and operator boundaries; caller cannot override it | No complete simulation memory taxonomy/consent/retention/world bridge | Separate world authority; no implicit real-world writes |
